# 待办事项应用

一个简单而功能完整的待办事项管理应用，使用纯 HTML、CSS 和 JavaScript 构建。

## 功能特性

- ✅ 添加待办事项
- ✅ 删除待办事项
- ✅ 标记完成/未完成
- ✅ 过滤显示（全部/未完成/已完成）
- ✅ 本地存储持久化
- ✅ 清除已完成项目
- ✅ 项目统计
- ✅ 响应式设计

## 使用方法

直接在浏览器中打开 `index.html` 文件即可运行。

## 技术栈

- HTML5
- CSS3
- 原生 JavaScript (ES6+)

## 浏览器支持

支持所有现代浏览器。
